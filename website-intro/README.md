# Website Intro

Explorations for the opening interaction on bengenin.com.

## Current direction

A short entrance sequence:

1. Full-screen dark charcoal background.
2. Small horizontal rectangle centered on screen.
3. Low-resolution monochrome TV static for roughly 1.3 seconds.
4. Static resolves to `Hey, I'm Ben` for roughly 0.9 seconds.
5. Intro fades away and reveals the homepage.

## Design constraints

- Minimal and editorial.
- Static should feel chunky and analog, not like fine digital noise.
- Avoid cyberpunk, hacker, VHS-glitch, or flashy effects.
- No sound, loading indicator, or logo.
- Keep the entire sequence short.
- Support desktop and mobile.
- Respect `prefers-reduced-motion`.

## Adjustable variables

- Static duration
- Text duration
- Rectangle width
- Rectangle aspect ratio
- Static pixel size
- Transition speed
