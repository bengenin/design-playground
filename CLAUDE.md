# CLAUDE.md

## Purpose

This repository is Ben's public design playground: a collection of small interface, interaction, typography, motion, and web experiments.

The repository should stay easy to browse, easy to run locally, and presentable to people viewing it on GitHub.

## Working rules

1. Keep each experiment self-contained in its own folder.
2. Do not modify unrelated experiments unless explicitly asked.
3. Prefer the simplest implementation that communicates the design idea.
4. Use plain HTML, CSS, and JavaScript for small prototypes unless a framework is clearly useful.
5. Keep visual output polished enough to share publicly, even when the experiment is intentionally rough.
6. Avoid unnecessary dependencies.
7. Preserve accessibility basics, including semantic HTML, keyboard usability where relevant, and `prefers-reduced-motion` for motion-heavy experiments.
8. Do not commit API keys, tokens, credentials, private files, customer data, or internal company material.
9. Before adding a dependency or changing the overall repository structure, explain why.
10. When finishing an experiment, update the root README if it should be discoverable from the repository homepage.

## Design direction

Favor restraint over decoration. Prioritize typography, spacing, hierarchy, proportion, interaction quality, and clear visual ideas. Avoid generic SaaS aesthetics, excessive cards, gratuitous gradients, cyberpunk effects, and over-animation unless the experiment specifically explores them.

## Repository structure

- `website-intro/` - entrance animations and identity experiments
- `navigation/` - navigation and menu studies
- `typography/` - typography and hierarchy studies
- `interactions/` - micro-interactions and motion
- `layouts/` - page composition and responsive layout studies
- `references/` - design references and notes
