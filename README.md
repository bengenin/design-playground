# Design Playground

A public collection of interface, interaction, typography, and web experiments by Ben Genin.

This repository is intentionally exploratory. Some ideas will stay rough prototypes, others may become polished components or make their way into larger projects.

## Experiments

- [`website-intro/`](./website-intro/) - entrance animations and identity experiments
- [`navigation/`](./navigation/) - navigation patterns and interaction studies
- [`typography/`](./typography/) - type treatments, hierarchy, and layout studies
- [`interactions/`](./interactions/) - micro-interactions and motion experiments
- [`layouts/`](./layouts/) - page composition and responsive layout studies
- [`references/`](./references/) - design references and notes

## Principles

- Keep each experiment self-contained.
- Prefer simple HTML, CSS, and JavaScript when a prototype does not need a framework.
- Optimize for clarity, restraint, strong typography, and thoughtful interaction.
- Treat unfinished work as part of the process.
- Never commit secrets, credentials, private data, or internal company material.

## Current experiment

The first prototype explores a short website entrance sequence using low-resolution TV static, a simple `Hey, I'm Ben` reveal, and a transition into a placeholder homepage.
